# Ajedrez en C (Raylib)

Proyecto de ajedrez desarrollado en C utilizando la biblioteca Raylib para la interfaz gráfica.

## Archivo principal
* **`prbchs1.c`**: Contiene la lógica central del tablero, validación de movimientos, control de turnos y renderizado gráfico.

## Estado del proyecto
Proyecto en desarrollo activo.
- [x] Movimientos básicos y validaciones de piezas
- [x] Enroque corto y largo
- [x] Detección visual de jaque
- [ ] Bloqueo de jugadas ilegales (piezas clavadas / auto-jaque)
- [ ] Oponente computarizado (IA básica)
